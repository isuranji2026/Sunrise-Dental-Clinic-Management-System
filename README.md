# Sunrise-Dental-Clinic-Management-System
I am planning to create Patient Appointment management desktop application for 'Sunrise Dental' Clinic because now they handle patient appointments and treatment records manually using paper files and notebooks. This has resulted in double bookings, lost patient records, long waiting times, and billing errors.

1. Open the project in VS Code
2. Open Git Bash Terminal in VS code (Terminal --> New Terminal). Then select 'Git Bash' from the terminal dropdown.
3. Check that you are in the correct folder
   Run: pwd . Then ls .

4. Complete Command sequence
   for Windows
rm -f *.class
javac -cp ".;lib/sqlite-jdbc-3.53.4.0.jar" *.java
java -cp ".;lib/sqlite-jdbc-3.53.4.0.jar" DentalClinicApp

   for MAC
rm -f *.class
javac -cp ".:lib/sqlite-jdbc-3.53.4.0.jar" *.java
java -cp ".:lib/sqlite-jdbc-3.53.4.0.jar" DentalClinicApp
